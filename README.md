# 🚀 CrackIt – Mastery Hub  
### Company-Wise Technical Interview Preparation Portal  

CrackIt is a structured web platform designed to help students and professionals prepare for technical interviews efficiently. It provides curated coding questions categorized by companies and topics, making preparation focused and effective.

👉 **Live Demo:** https://crackit-master.onrender.com/

---

## ✨ Features  

- 📂 **Structured Question Bank** – Organized company-wise and topic-wise  
- 💡 **Real Interview Questions** – Based on industry-level interview patterns  
- 📖 **Clear Explanations** – Helps in deep conceptual understanding  
- 🎯 **Focused Preparation** – Practice without distractions  
- ⚡ **Fast & Simple UI** – Lightweight and easy to use  

---

## 🚀 Tech Stack  

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Python (Django)  
- **Database:** SQLite  
- **Deployment:** Render
